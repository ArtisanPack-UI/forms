## Quick Reference

### Models

| Model | Description |
|-------|-------------|
| `Form` | Form definition and settings |
| `FormField` | Individual form fields |
| `FormStep` | Multi-step form steps |
| `FormSubmission` | Submitted form data |
| `FormSubmissionValue` | Individual field values |
| `FormUpload` | File upload metadata |
| `FormNotification` | Email notification settings |

### Services

| Service | Description |
|---------|-------------|
| `FormService` | Form CRUD operations |
| `FieldService` | Field management |
| `StepService` | Multi-step management |
| `SubmissionService` | Submission processing |
| `NotificationService` | Email notifications |
| `ConditionalLogicService` | Condition evaluation |
| `ExportService` | Data export |
| `IntegrationService` | Third-party integrations |

For detailed API documentation, see [API Overview](./api/api.md).
